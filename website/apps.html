The same philosophy as Anchor, applied to a few other things: local-first, no accounts, no telemetry, free and open source.

Desktop apps

Native utilities for the desktop: two floating companions built on the same WinUI 3 foundation as Anchor, and a cross-platform workbench for certificates.

Windows app

SwiftX

Everything you reach for, right where you are. A quick-access orbit for apps, files, folders and links, summoned with a shortcut, a screen corner or the system tray.

Website Microsoft Store GitHub
Windows · macOS · Linux

Keystore Studio

Keystores, without the guesswork. A desktop workbench for Java keystores, PKCS#12 files and X.509 certificates: open, convert, sign, audit and inspect, with every cryptographic operation running locally in a Rust engine.

Website Get it GitHub
Windows app

DockDev

A floating toolbox for developers. Formats JSON, decodes JWTs, hashes files and masks personal data, all processed locally, so nothing leaves your PC.

Microsoft Store GitHub

Focused tools that stay inside the editor, published to both the VS Code Marketplace and Open VSX.

Extension

VsGit

A full-featured Git client for VS Code. Drives the real git binary, with 173 commands and a commit graph.
